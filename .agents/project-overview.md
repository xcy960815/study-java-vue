# Project Overview

## Purpose

This project is a Vue 3 admin/frontend for a Spring Boot learning/back-office system. It has CRUD-style system pages, monitoring/report pages, upload demos, order/goods pages, and DeepSeek/Ollama chat/model views.

## Runtime Shape

- Local development runs through Vite.
- Builds emit static assets into `dist/`.
- Docker builds use Node 18 to run `pnpm run build:prod`, then serve `dist/` with Nginx.
- Vite reads environment files from `env/` rather than the project root.

## Main Directories

- `src/main.ts`: creates the Vue app and installs global components, Pinia, permission directive plugin, and router.
- `src/App.vue`: root router outlet.
- `src/router/`: base routes, auth guard, dynamic route loading.
- `src/store/`: Pinia stores for user, system, and login state.
- `src/apis/`: typed API wrapper functions grouped by feature.
- `src/utils/`: request transport, route building, AI core utilities, token handling, websocket, style helpers.
- `src/composables/`: Vue composition utilities including permissions, encryption, async state, login animation, and AI chat session helpers.
- `src/components/`: shared components, layout shell, SVG/icon wrappers, AI chat UI.
- `src/views/`: page-level Vue components grouped by domain.
- `src/assets/`: styles, images, and SVG icon sources.
- `src/plugins/`: app plugins and Vite helper plugin code.
- `types/`: global TypeScript declarations for API DTO/VO shapes, store types, route metadata, and AI types.
- `env/`: `.env.daily`, `.env.pre`, `.env.prod` for mode-specific Vite variables.
- `public/`: static files served by Vite. `public/file-structure.json` is generated.

## Page Domains

- Auth: `src/views/login`, `src/views/register`, `src/views/password`
- System management: `src/views/system/menu`, `src/views/system/user`, `src/views/system/role`, `src/views/system/data-dictionary`
- Monitoring/reporting: `src/views/monitor/operlog`, `src/views/monitor/server`, `src/views/monitor/report`
- Business demos: `src/views/goods`, `src/views/order`, `src/views/file-upload`
- AI integrations: `src/views/deepseek/**`, `src/views/ollama/**`, `src/components/ai-chat/**`

## Generated Or External Output

Do not hand-edit these paths:

- `node_modules/`: installed dependencies.
- `dist/`: Vite build output.
- `coverage/`: test coverage output if generated.
- `*.tsbuildinfo`: TypeScript incremental metadata.
- `public/file-structure.json`: generated by `src/plugins/file-structure.ts`.
- `visualizer.html`: generated by Rollup visualizer in daily/development builds.
- `auto-imports.d.ts`: generated by auto-import tooling.
- `components.d.ts`: generated by component auto-registration tooling.

## Package And Config Files

- `package.json`: scripts, dependencies, Volta Node pin.
- `pnpm-lock.yaml`: lockfile; update through `pnpm`, do not edit by hand.
- `vite.config.ts`: env loading, proxy, aliases, SVG sprite plugin, Element Plus auto import, output chunking, file-structure generator.
- `vitest.config.ts`: merges Vite config and configures Vitest with `jsdom`.
- `tsconfig*.json`: project references and path aliases.
- `Dockerfile`, `nginx.conf`: production container/static serving.
- `.husky/*`, `commitlint.config.cjs`: pre-commit formatting and commit message checks.
